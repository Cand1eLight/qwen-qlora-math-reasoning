# Additional comparisons

Run these scripts after `run_experiments.py --full` completes a fresh main run.
They use its dataset snapshots and adapter checkpoints.

| Directory | Comparisons |
| --- | --- |
| `extensions_v1/` | rank 8 / alpha 16 vs. rank 16 / alpha 32; 256 vs. 512 generated tokens |
| `extensions_v2/` | target cleaning; repeated training-question control; MathQA mixture; error analysis |

Both capacity settings hold alpha/rank at 2. The token-budget checks use the
same fixed 200-question validation slice. The four newly trained adapters use
two epochs and are evaluated on both complete test sets.

MathQA preparation accepts numeric choices that agree with supported arithmetic
programs. It checks internal duplicates and lexical overlap with all supplied
GSM8K/SVAMP questions. The filtered-data audit records every rejection category.

The pipeline targets Linux/WSL2 because its job coordination uses `fcntl` locks.
It checks other GPU compute processes before starting new work and retains
batch/epoch checkpoints for resumption.

Historical measurements are in `results/recorded/`, separate from files
generated by these scripts on a new run.
