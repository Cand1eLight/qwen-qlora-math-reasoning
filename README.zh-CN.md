# Qwen 的 QLoRA 数学推理微调

这个项目比较两种监督方式：只学习最终数值答案，以及学习解题过程和
最终答案。基础模型为 Qwen2.5-1.5B-Instruct；训练使用 GSM8K，评测同时
覆盖 GSM8K 和外部数据集 SVAMP。

| 模型 | GSM8K 准确率 | SVAMP 准确率 |
| --- | ---: | ---: |
| 原始模型 | 3.03% | 3.10% |
| 仅答案微调 | 12.05% | 35.30% |
| 解题过程微调 | 48.52% | 55.70% |

原始模型的低分主要来自严格格式下的答案提取失败，不能直接等同于它
只有约 3% 的数学能力。仅答案微调几乎完全学会了 `#### <答案>` 的输出
格式；解题过程微调则明显提高数值正确率。

![正确、可提取但错误、提取失败的比例](figures/outcome_decomposition.png)

补充实验包含错误分析、LoRA 容量、生成长度、目标清洗、MathQA 外部
数据混合及等样本量的重复题对照，共有 18 项补充评测。MathQA 混合训练
达到 47.92% / 55.90%，高于重复题对照的 43.75% / 52.10%，但没有同时
超过原解题过程模型的两个基准成绩。

仓库提供训练代码、完整配置、指标、逐题生成输出的精简导出、训练
历史、过滤审计和报告。可以先打开
[结果 Notebook](notebooks/results_review.ipynb) 查看数据；运行条件和
命令见 [英文 README](README.md)。完整训练流程使用 Linux 或 WSL2
及 NVIDIA GPU，记录中的硬件是 RTX 5090。

代码来自课程实验中完成的训练与评测实现，公开版改为项目相对路径，
固定模型和数据集版本。已有数值结果来自实际完成的单种子实验；新的
训练会生成自己的结果和运行指纹。
